Owner feedback (2026-08-30, angry, after two outward drafts): stop writing
like AI when drafting AS them. The writing-style rule file covers repo prose;
this is about PERSONAL drafts (emails, Discourse posts), where the bar is
"would Ruben type this".

**Why:** the first Karolinska post draft was rejected outright ("it sounds so
much like AI, I'm sick of it"). What made it AI: a meta-structure
announcement ("I would like to offer two things and ask one question"), an
interest-signalling opener ("I have been following this thread with a lot of
interest"), essayistic pivots ("What might matter more than the code is…"),
a "not X but Y" tell ("checkable rather than asserted"), and sign-off padding.

**How to apply:**
- Lead with the actual question or point, first sentence.
- Short paragraphs, one idea each; total length a developer would type.
- Never announce the structure of what follows.
- Ruben's register (from his own messages): direct, practical, a little
  informal, honest about limitations without hedging ("fair warning: it's
  young and I'm the only maintainer").
- Cut every opener/closer that exists only to be polite; one short closing
  line at most ("Happy to talk either way").
- Discourse posts are MARKDOWN; Outlook emails are plain-text .txt files on
  the Desktop.
